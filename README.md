# Tienda Online (HTML, CSS y JavaScript)

## Estado del proyecto
Este proyecto se encuentra actualmente en construcción.  
Algunas secciones y funcionalidades están en desarrollo o pendientes de mejora.


Esta es una **página web tipo e-commerce** creada con **HTML, CSS y JavaScript puro**, inspirada en una tienda de muebles o productos del hogar.  
Presenta un diseño moderno con carrusel de imágenes, categorías interactivas y una sección de productos destacados generados dinámicamente desde JavaScript.


## Funcionalidades principales
- Carrusel de imágenes con botones de navegación.  
- Menú de navegación superior con distintas secciones.  
- Sección de categorías con efectos *hover* interactivos.  
- Productos destacados generados desde JavaScript.  
- Diseño limpio y responsive, con variables CSS y tipografía personalizada.
